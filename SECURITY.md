# Security policy

This project has no public deployment or maintained security-contact channel yet. Do not include real personal data, generated contracts, credentials, or other sensitive information in issues or pull requests.

If GitHub's private vulnerability reporting feature is enabled for the repository where this project is hosted, use it to report suspected vulnerabilities. Otherwise, this preview offers no confidential reporting route. Do not disclose exploit details, credentials, or other sensitive information in a public issue or pull request. Maintainers and a staffed confidential security-reporting route must be established before the project offers ongoing security support.

The offline export command reads document values from standard input. It does not transmit or retain those inputs separately; generated documents are written only to the explicit output path. PDF conversion uses temporary files and an isolated LibreOffice profile that are removed when conversion ends.

Security reports should state the affected version, reproducible steps, and potential impact without exposing third-party data.
